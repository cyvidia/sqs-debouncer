# sqs-debouncer

Debounce AWS SQS messages based on content. Dedupe based on a unique id/hash derived from your message content. Built off of https://github.com/fcouceiro/sqs-debouncer/tree/main.

## Installation

To install this package, simply enter the following command into your terminal (or the variant of whatever package manager you are using):

```bash
npm install https://github.com/cyvidia/sqs-debouncer.git
```
